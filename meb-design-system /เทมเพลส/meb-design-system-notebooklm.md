# ระบบดีไซน์ร้านอีบุ๊ก "meb" — เอกสารอ้างอิงฉบับสมบูรณ์
### (สำหรับใช้กับ NotebookLM หรือ AI ตัวใดก็ได้ เพื่อเรียนรู้และคงความสม่ำเสมอของธีมเมื่อสร้างหน้าใหม่)

---

## บทนำ: เอกสารนี้ใช้ทำอะไร

เอกสารฉบับนี้สรุปธีมภาพ (visual theme), คอมโพเนนต์ (UI components), และ **วิธีคิด** ในการจัดวางองค์ประกอบ (layout composition) ของเว็บไซต์ร้านอีบุ๊กสไตล์ "meb" โดยวิเคราะห์จากหน้าเว็บต้นแบบ 3 หน้า:

1. **Homepage เวอร์ชันย่อ** — มี banner + 2 sections (ใหม่มาแรง, มาใหม่)
2. **หน้ารายละเอียดหนังสือ (Product Detail Page)** — หน้าขายสินค้าเดี่ยว มีกล่องราคา ปุ่มซื้อ เนื้อเรื่องย่อ
3. **Homepage เวอร์ชันเต็ม** — มี sidebar หมวดหมู่ + banner carousel + 3 sections (ขายดี, มาใหม่, ฟรีกระจาย) + footer แบบเต็ม

เป้าหมายของเอกสารนี้คือให้ **AI หรือทีมออกแบบที่จะสร้างหน้าใหม่ในอนาคต** สามารถ:
- ใช้สี ฟอนต์ ไอคอน ที่ตรงกับของเดิมเป๊ะ (ไม่เดาเอง ไม่ใช้สีใกล้เคียงแต่ไม่ตรง)
- รู้ว่าคอมโพเนนต์ไหนมีอยู่แล้ว ควรหยิบมาใช้ซ้ำ ไม่ต้องออกแบบใหม่
- ที่สำคัญที่สุด: **รู้ว่าหน้าประเภทไหน ควรจัดวางองค์ประกอบแบบไหน** — เพราะการ "มีคอมโพเนนต์ครบ" ไม่ได้แปลว่า "ใช้ถูกที่" เสมอไป (เช่น banner carousel เหมาะกับหน้าแรก แต่ไม่ควรมีในหน้า checkout)

## ส่วนที่ 1: Design Tokens (สี ฟอนต์ ไอคอน ระยะ)

### 1.1 สี (Colors)

**สีแบรนด์ (เขียว) — สีหลักของระบบ**

| ชื่อ | Hex | ใช้ตรงไหน |
|---|---|---|
| Brand green (หลัก) | `#00a651` | พื้นหลัง header, ปุ่ม action หลัก, active state ของแท็บ/เมนู, accent bar หน้าหัวข้อ section, ลิงก์ |
| Brand hover | `#008c44` | hover state ของปุ่ม/ลิงก์สีเขียว |
| Brand light | `#e6f6ec` | พื้นหลังอ่อนของ tag, focus ring, hover ของแถบเมนู |
| Nav variant | `#009348` | ใช้แยกโทนของ header กับ nav รองในหน้าที่ซับซ้อนขึ้น |

**สีราคา/โปรโมชัน (แดง) — สีเตือน/กระตุ้นการตัดสินใจ**

| ชื่อ | Hex | ใช้ตรงไหน |
|---|---|---|
| Price red (หลัก) | `#e53935` | ราคาที่ลดแล้ว, ป้าย % ส่วนลด, tag โปรโมชัน, badge จำนวนของในตะกร้า |
| Ribbon red | `#e11d48` | ริบบอน "Best Seller" |
| เงาริบบอนเข้ม | `#9f1239` / `#b71c1c` | เงาใต้ริบบอน สร้างเอฟเฟกต์พับมุม |

**สีข้อความ/พื้นหลังทั่วไป**

| ชื่อ | Hex/Class | ใช้ตรงไหน |
|---|---|---|
| Text หลัก | `#333333` | เนื้อหาตัวอักษรทั่วไป |
| Text รอง | `slate-500` | คำบรรยายรอง, ชื่อผู้แต่ง, breadcrumb |
| Text จาง | `slate-400` | placeholder, จำนวน rating, ราคาปกขีดฆ่า |
| Page background | `#f8f9fa` หรือ `#f0f2f5` | พื้นหลังทั้งหน้า (เลือกใช้ค่าเดียวตลอดทั้งเว็บ) |
| Card background | `#ffffff` | การ์ด, section wrapper |
| Border | `#e5e7eb` | เส้นขอบการ์ด, เส้นแบ่ง |

**สี rating และ badge พิเศษ**

- ดาว rating เต็ม: `yellow-400` / ดาวว่าง: `slate-300`
- เหรียญอันดับ 1: gradient ทอง `#ffd700 → #ffaa00`
- เหรียญอันดับ 2: gradient เงิน `#e0e0e0 → #9e9e9e`
- เหรียญอันดับ 3: gradient ทองแดง `#ffbca8 → #d87a5d`
- เหรียญอันดับ 4 ขึ้นไป: พื้นดำ `#333` ตัวขาว

**กล่องแจ้งเตือน/โปรโมชันพิเศษ**

- กล่องราคา/โปรโมชัน (เหลืองอ่อน): พื้น `#fcf8e3` ขอบ `#faebcc` — ใช้กับกล่องราคา+ปุ่มซื้อ
- กล่อง alert ข้อมูล (ฟ้าอ่อน): พื้น `#e3f2fd` ขอบ `#bbdefb` ตัวหนังสือ `#1976d2`/`#1565c0` — ใช้แจ้งข้อมูลเสริมที่ไม่ใช่ error

### 1.2 ฟอนต์ (Typography)

- **Font family**: Noto Sans Thai เท่านั้น โหลดจาก Google Fonts (`family=Noto+Sans+Thai:wght@300;400;500;600;700`)
- น้ำหนัก 400 = เนื้อความปกติ, 500 = label/nav, 600 = คำสำคัญรอง, 700 (bold) = หัวข้อ/ราคา/ชื่อหนังสือ/ปุ่ม
- ลำดับขนาด: Section title `text-lg`–`text-2xl font-bold` > Page title (หน้ารายละเอียด) `text-2xl md:text-3xl font-bold` > Book card title `text-sm font-bold` (จำกัด 2 บรรทัดด้วย line-clamp) > Body/metadata `text-xs`–`text-sm`

### 1.3 ไอคอน (Icons)

- ใช้ **Phosphor Icons** เท่านั้น (`ph ph-{name}` สำหรับ outline, `ph-fill ph-{name}` สำหรับ filled) โหลดจาก `unpkg.com/@phosphor-icons/web`
- ไอคอนหลักที่ใช้ซ้ำ: ค้นหา, ตะกร้า, โปรไฟล์, หัวใจ (wishlist), ดาว (rating), caret ต่างๆ (dropdown/breadcrumb/carousel), list (หมวดหมู่/hamburger), tag (โปรโมชัน), gift (ฟรี/ของขวัญ), trophy (ขายดี), books (หมวดหมู่)

### 1.4 Layout & Spacing

- Container width: `max-w-7xl` (≈1280px) หรือ `max-w-[1200px]` เลือกใช้ค่าเดียวตลอดทั้งเว็บ
- Grid หนังสือ: มือถือ 2 คอลัมน์ → แท็บเล็ต 3 คอลัมน์ → เดสก์ท็อป 4 คอลัมน์ (ถ้ามี sidebar) หรือ 5 คอลัมน์ (ถ้าไม่มี sidebar)
- Border radius: การ์ดใหญ่ `rounded-lg/xl`, ปกหนังสือ `rounded-md` หรือเกือบเหลี่ยม `rounded-[2px]` (ให้ความรู้สึกเหมือนปกหนังสือจริง), ปุ่มสี่เหลี่ยม `rounded-md`, ปุ่มไอคอนกลม `rounded-full`
- Shadow: `shadow-sm` เป็นค่าเริ่มต้นของการ์ดทุกใบ, `shadow-md` เฉพาะตอน hover หรือกล่อง CTA ที่ต้องการความเด่น
- Header: `sticky top-0 z-50` เสมอ / Sidebar (ถ้ามี): `sticky top-[80px]`

## ส่วนที่ 2: คอมโพเนนต์ (Components)

### 2.1 Header

พื้นหลังเขียวแบรนด์ ลอยติดบนสุดตลอด (`sticky`) โครง: โลโก้ (ซ้าย) — ช่องค้นหา (กลาง/ขวา ซ่อนบนมือถือ) — ตะกร้า+โปรไฟล์ (ขวาสุด) ไอคอนตะกร้ามี badge ตัวเลขสีแดงมุมขวาบนแสดงจำนวนสินค้า ทุกหน้าต้องใช้ header เดียวกันเป๊ะ ไม่ออกแบบใหม่ต่อหน้า

### 2.2 Secondary Nav (แถบเมนูรองสีขาว)

มี 3 รูปแบบตามความหนาแน่นของเนื้อหา: (1) แบบแท็บเลื่อนแนวนอนได้พร้อมหัวข้อกลาง สำหรับหน้าแรกเรียบง่าย (2) แบบโชว์หมวดหมู่ที่เกี่ยวข้องกับสินค้าเป็นลิงก์ สำหรับหน้ารายละเอียด (3) แบบเต็มมีปุ่ม "หมวดหมู่ทั้งหมด" + แท็บมีไอคอนกำกับแต่ละอัน สำหรับหน้าแรกที่ซับซ้อน แท็บ active จะมีเส้นใต้สีเขียว ส่วนแท็บ "โปรโมชัน" มักใช้สีแดงแทนสีเทาเริ่มต้นเพื่อดึงสายตา

### 2.3 Sidebar หมวดหมู่ (เดสก์ท็อปเท่านั้น)

กว้างคงที่ประมาณ 240px ลอยติดตามการเลื่อน (sticky) หัวกล่องพื้นเขียว รายการหมวดหมู่คั่นด้วยเส้นบาง รายการสุดท้ายเป็นลิงก์ "ดูหมวดหมู่ทั้งหมด" ตัวหนาสีเขียว **ใช้เฉพาะหน้ารายการที่ต้องการให้กรอง/เลือกหมวดหมู่ง่ายๆ ไม่ใช้ในหน้ารายละเอียดสินค้าเพราะเปลืองพื้นที่และแย่งโฟกัส**

### 2.4 Banner Carousel

แถวรูปเลื่อนแนวนอนแบบ snap-scroll มีจุด pagination ด้านล่างและปุ่มลูกศรซ้าย-ขวาที่โผล่ตอน hover **ใช้เฉพาะหน้าแรก/หน้ารวมโปรโมชันเท่านั้น** ไม่ใช้ในหน้ารายละเอียดสินค้าหรือหน้าธุรกรรม (checkout ฯลฯ) เพราะจะดึงความสนใจออกจากเป้าหมายหลักของหน้า

### 2.5 Section Wrapper

กล่องขาวมนพร้อมเงาบางๆ ห่อแต่ละหมวดเนื้อหาบนหน้ารายการ หัวข้อ section มี accent นำหน้าสองแบบ: แท่งสีเขียวบาง (สำหรับ section ทั่วไป เช่น "มาใหม่") หรือไอคอนสีเฉพาะเรื่อง เช่น ถ้วยรางวัลสีทองสำหรับ "ขายดี" ไอคอนของขวัญสีชมพูสำหรับ "ฟรีกระจาย" (สำหรับ section ที่มีความหมายเฉพาะตัวชัดเจน) มุมขวาของหัวข้อมีลิงก์ "ดูทั้งหมด" สีเขียวเสมอ

### 2.6 Book Card — คอมโพเนนต์สำคัญที่สุดของระบบ

โครงร่วม: รูปปก (อัตราส่วน 2:3 หรือ 1:1.4) → ชื่อหนังสือ (จำกัด 2 บรรทัด) → ผู้แต่ง → หมวดหมู่/สนพ. → แถวล่างสุด (rating ซ้าย, ราคาขวา)

**สามสไตล์ป้าย (badge) ที่ห้ามผสมกันแบบสุ่มในกริดเดียว เพราะแต่ละแบบสื่อความหมายต่างกัน:**

1. **ป้าย % ส่วนลด** — มุมซ้ายบนของรูป สี่เหลี่ยมพื้นแดง ใช้เมื่อมีส่วนลดจริงไม่ว่า section ไหน
2. **ริบบอน "Best Seller"** — มุมขวาบน ทรงริบบอนพับมุม พื้นแดงเข้ม ใช้เน้นเล่มเด่นแซมในกริดทั่วไป (ไม่ใช่ section จัดอันดับ)
3. **เหรียญอันดับ (rank badge)** — มุมซ้ายบนวงกลมลอยออกนอกขอบการ์ด แสดงเลข 1/2/3/4+ พร้อมสีทอง/เงิน/ทองแดง/ดำตามลำดับ **ใช้เฉพาะ section ที่มีการจัดอันดับจริง เช่น "ขายดีประจำสัปดาห์" เท่านั้น**

Rating stars ใช้ไอคอนดาว 5 ดวงเสมอแม้ยังไม่มีรีวิว (แสดงดาวสีเทาจางทั้งหมดแทนการซ่อนแถว) เพื่อให้โครงสร้างการ์ดสูงเท่ากันทุกใบในกริด

ราคาแบบมีปุ่ม (พื้นเขียว ตัวหนังสือขาว) ใช้กับการ์ดที่มีขนาดใหญ่กว่า/เนื้อหาน้อยกว่า ส่วนราคาแบบตัวเลขเขียวเปล่า (ไม่มีปุ่ม) ใช้กับกริดที่หนาแน่นกว่าเพื่อประหยัดพื้นที่ — ราคาที่มีส่วนลด: ราคาปกขีดฆ่าสีเทาจางอยู่เหนือราคาใหม่

### 2.7 Price Box (กล่องราคา+ปุ่มซื้อ) — เฉพาะหน้ารายละเอียดสินค้า

พื้นหลังเหลืองอ่อน มีแถบมุมขวาบนสีแดงระบุระยะเวลาโปรโมชัน ราคาตัวใหญ่สีแดงคู่กับราคาปกขีดฆ่าและ "ประหยัด N%" ปุ่มคู่: ปุ่ม outline เขียว (secondary action เช่น "ทดลองอ่าน") + ปุ่มพื้นเขียวเข้ม (primary action "ซื้อเลย") ใต้กล่องมีแถว secondary actions แบบ text+icon (wishlist, ซื้อเป็นของขวัญ)

### 2.8 Info/Alert Box

โทนฟ้าอ่อน ใช้แจ้งข้อมูลเสริมที่ไม่ใช่ error/warning จริงจัง วางท้ายเนื้อหาหลักก่อน footer

### 2.9 Info Grid

ตาราง label-value พื้นเทาอ่อน ใช้แสดง metadata ที่มีคู่ label-value ชัดเจน เช่น ซีรีส์ นักวาด ประเภทไฟล์ วันวางขาย

### 2.10 Tags

pill เล็กมุมโค้งเต็ม tag หลักใช้พื้นเขียวอ่อน tag รองใช้พื้นเทา

### 2.11 Social Share Buttons

ปุ่มวงกลมสีตามแบรนด์จริงของแต่ละแพลตฟอร์ม (Facebook, X, Line) บวกปุ่มคัดลอกลิงก์พื้นเทา

### 2.12 Footer — สองแบบ

- **แบบเรียบ**: พื้นขาว ข้อความลิขสิทธิ์บรรทัดเดียวกลางหน้า — ใช้กับหน้าลึกที่โฟกัสงานเดียว (รายละเอียดสินค้า, checkout) เพื่อไม่ดึงความสนใจออกจาก CTA
- **แบบเต็ม**: พื้นเข้ม แบ่ง 4 คอลัมน์ (เกี่ยวกับ/หมวดหมู่ยอดนิยม/ดาวน์โหลดแอป+โซเชียล) — ใช้กับหน้าแรก/หน้า landing ที่ต้องการช่วยนำทางและ SEO

## ส่วนที่ 3: วิธีคิดจัดวางองค์ประกอบตามประเภทหน้า (Page Composition Framework)

นี่คือส่วนสำคัญที่สุดสำหรับการต่อยอดสร้างหน้าใหม่ในอนาคต — **หลักการคือ: หน้าใหม่ทุกหน้าต้องถูกจัดกลุ่มก่อนว่าอยู่ในกลุ่มไหนใน 4 กลุ่มด้านล่าง แล้วค่อยเลือกองค์ประกอบตามกลุ่มนั้น ไม่ใช่หยิบทุกคอมโพเนนต์มาใส่หมด**

### ขั้นตอนคิดก่อนออกแบบหน้าใหม่

1. หน้านี้อยู่ในกลุ่มไหนใน 4 กลุ่ม (Listing / Detail / Transactional / Account) → เลือกโครงหน้าตามกลุ่ม
2. ผู้ใช้เข้าหน้านี้เพื่อ "สำรวจ/เลือกดูหลายรายการ" หรือ "โฟกัสตัดสินใจเรื่องเดียว"? สำรวจ → มี sidebar/filter, grid หนาแน่น, banner ได้ / โฟกัสเดียว → ไม่มี sidebar ไม่มี banner เน้นพื้นที่ว่างรอบ CTA
3. มีข้อมูลที่ต้องเปรียบเทียบไหม (ราคาก่อน-หลัง, อันดับ, คะแนน)? ถ้ามีให้ใช้ badge/สีตามกฎที่กำหนดไว้อย่างเคร่งครัด ไม่ผสมความหมาย
4. เลือก footer ให้ตรงกับความลึกของหน้า
5. เช็ค responsive ครบ 3 breakpoint เสมอ

### กลุ่มที่ 1: หน้ารายการ/สำรวจเนื้อหา (Listing / Browse)

ตัวอย่าง: หน้าแรก, หน้าหมวดหมู่ย่อย, หน้าค้นหา, หน้าโปรโมชันรวม

โครง: Header → Secondary Nav → (Sidebar ถ้าตัวกรองเยอะ) → Banner (เฉพาะหน้าแรก/แคมเปญจริง) → หลาย Section ต่อกัน (แต่ละ section เลือก badge ให้ตรงความหมาย) → Footer แบบเต็ม

กฎเสริม: หน้าหมวดหมู่เจาะจงควรเป็น grid เดียวยาวพร้อม sort/filter แทนการแบ่งหลาย section หน้าค้นหาควรมีแถบสรุปผล ("พบ N รายการ") แทนหัวข้อ section ปกติ

### กลุ่มที่ 2: หน้ารายละเอียดสินค้า/เนื้อหาเดี่ยว (Detail / PDP)

ตัวอย่าง: หน้ารายละเอียดหนังสือ, หน้ารายละเอียดผู้แต่ง

โครง: Header + Secondary Nav (breadcrumb-in-category ได้) → Breadcrumb → การ์ดเนื้อหาขาวใหญ่ 2 คอลัมน์ (ปกใหญ่+แชร์โซเชียล ซ้าย / ชื่อเรื่อง+meta+rating+Price Box+Info Grid+เนื้อเรื่อง+tags ขวา) → Info/Alert เสริม (ถ้ามี) → Footer แบบเรียบ

กฎเสริม: ห้ามมี sidebar และ banner (แย่งโฟกัสจาก CTA ซื้อ) ปุ่มซื้อต้องอยู่เหนือ fold เสมอแม้บนมือถือ ถ้าเนื้อหาละเอียดอ่อนต้องมีคำเตือนสั้นก่อนเนื้อเรื่อง ไม่ซ่อนเป็นค่าเริ่มต้น สินค้าแนะนำเพิ่มเติม (ถ้ามี) ใส่แบบ section กลุ่ม 1 ต่อท้ายก่อน footer เท่านั้น

### กลุ่มที่ 3: หน้าธุรกรรม (Transactional)

ตัวอย่าง: ตะกร้าสินค้า, checkout, ยืนยันการชำระเงิน (ต้นแบบไม่มีหน้านี้ตรงๆ ให้ยึดหลักกลุ่ม 2 บวกกฎเสริม)

โครง: Header แบบย่อ (ตัดช่องค้นหาได้) + progress indicator ไฮไลต์ขั้นตอนปัจจุบันด้วยสีเขียว → เนื้อหา 2 คอลัมน์ (รายการ/ฟอร์ม ซ้าย กว้างกว่า, สรุปยอด sticky ขวา ใช้สไตล์กล่องเหลืองเดียวกับ Price Box) → ปุ่ม primary เต็มความกว้างการ์ดสรุปยอด → Footer แบบเรียบ

กฎเสริม: ห้ามมี banner/สินค้าแนะนำแทรกระหว่างขั้นตอนชำระเงินเด็ดขาด (เพิ่มความเสี่ยง cart abandonment) แนะนำสินค้าเพิ่มได้เฉพาะก่อนเข้าสู่ checkout เท่านั้น

### กลุ่มที่ 4: หน้าบัญชีผู้ใช้ (Account / Profile)

ตัวอย่าง: โปรไฟล์, ประวัติการสั่งซื้อ, Wishlist, ตั้งค่า (ต้นแบบไม่มีหน้านี้ตรงๆ ให้ยึดโครงกลุ่ม 1 แต่เปลี่ยน sidebar จากหมวดหมู่หนังสือเป็นเมนูบัญชี)

กฎเสริม: Wishlist ใช้ Book Card เดิมแต่เปลี่ยนป้ายส่วนลดเป็นปุ่ม "นำออก" มุมขวาบน ประวัติการสั่งซื้อใช้ Info Grid style ต่อหนึ่งออเดอร์ ไม่ใช้ book card grid

## ส่วนที่ 4: Checklist ก่อนส่งงานหน้าใหม่ทุกครั้ง

- Header/โลโก้/สีเขียวแบรนด์ตรงกับ token ที่กำหนดเป๊ะ ไม่เพี้ยนเฉด
- ฟอนต์ Noto Sans Thai โหลดถูกต้อง ไอคอนเป็น Phosphor ทั้งหมด ไม่ผสมชุดไอคอนอื่น
- เลือกโครงหน้าตรงกับ 1 ใน 4 กลุ่มข้างต้น ไม่ผสมองค์ประกอบข้ามกลุ่มโดยไม่มีเหตุผล (เช่น อย่าใส่ banner ในหน้า checkout)
- Badge บนการ์ดหนังสือใช้ตรงความหมายเสมอ (rank เฉพาะ section ขายดี, ribbon เน้นเล่มเด่น, % เฉพาะมีส่วนลดจริง)
- Responsive ครบอย่างน้อย 3 breakpoint (มือถือ/แท็บเล็ต/เดสก์ท็อป) และซ่อน sidebar/banner ถูกจุดบนมือถือ
- เลือก footer ให้ตรงกับความลึกของหน้า (เต็ม vs เรียบ)
- สีแดงใช้เฉพาะราคา/ส่วนลด/ความเร่งด่วน ไม่เคยใช้เป็นปุ่ม action หลัก (ปุ่ม action หลักเป็นสีเขียวแบรนด์เสมอ)

## ภาคผนวก: External dependencies มาตรฐานที่ต้องใส่ในทุกหน้า

```html
<script src="https://cdn.tailwindcss.com"></script>
<link href="https://fonts.googleapis.com/css2?family=Noto+Sans+Thai:wght@300;400;500;600;700&display=swap" rel="stylesheet">
<script src="https://unpkg.com/@phosphor-icons/web"></script>
<script>
  tailwind.config = {
    theme: {
      extend: {
        fontFamily: { sans: ['Noto Sans Thai', 'sans-serif'] },
        colors: {
          meb: { green: '#00a651', hover: '#008c44', light: '#e6f6ec' },
          price: { red: '#e53935' }
        }
      }
    }
  }
</script>
```
