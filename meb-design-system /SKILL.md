# Meb E-book Store — Design System Skill

สกิลนี้สรุปธีมภาพ (visual theme) และแนวคิดการจัดวางองค์ประกอบ (layout composition) จากหน้าเว็บต้นแบบ 3 หน้า ของร้านอีบุ๊กสไตล์ "meb":

1. หน้าแรก (เวอร์ชันเรียบง่าย) — banner + 2 sections
2. หน้ารายละเอียดหนังสือ (product detail page)
3. หน้าแรก (เวอร์ชันสมบูรณ์) — sidebar + banner + 3 sections + footer เข้ม

เป้าหมาย: เมื่อต้องสร้าง "หน้าใหม่" หรือ "คอมโพเนนต์ใหม่" ในธีมนี้ ให้ผลลัพธ์ออกมา**เนียนเป็นเนื้อเดียวกัน**กับของเดิม ไม่ใช่แค่ "ใช้สีเขียวเหมือนกัน" แต่ต้องเลือก layout pattern, component, และลำดับความสำคัญของสี ให้ตรงกับ "ประเภทของหน้า" นั้นๆ

## วิธีใช้สกิลนี้ (ลำดับการอ่าน)

1. **อ่าน `references/design-tokens.md` ก่อนเสมอ** — สี ฟอนต์ ไอคอน ระยะ/รัศมีมุม ที่เป็นมาตรฐานของธีม ห้ามเดาสีเอง ห้ามใช้สีเขียว/แดงอื่นที่ไม่อยู่ในลิสต์
2. **อ่าน `references/components.md`** — ชิ้นส่วน UI สำเร็จรูปที่มีอยู่แล้ว (header, การ์ดหนังสือ, กล่องราคา, ริบบอน ฯลฯ) พร้อมโค้ด Tailwind ตัวอย่าง และกฎว่าคอมโพเนนต์ไหนใช้กับหน้าแบบไหน
3. **อ่าน `references/page-patterns.md`** — วิธี "คิด" ว่าหน้าใหม่ควรจัดวางองค์ประกอบแบบไหน ตามประเภทหน้า (listing / detail / transactional / account) รวมทั้ง checklist ก่อนส่งงาน

ถ้างานที่ขอเป็นการ "แก้หน้าเดิม" (เอกสารที่แนบมา) ให้แก้แบบยึดโครงเดิมไว้ก่อน แล้วเทียบกับ tokens/components ในสกิลนี้ว่ามีจุดไหนหลุดธีมหรือไม่ (เช่น ใช้สีที่ไม่ตรง, ใช้ font อื่น, ลืม hover state, ลืม responsive breakpoint)

## กฎเหล็ก 5 ข้อ (อย่าลืม)

1. **สีเขียว `#00a651` (brand) ใช้กับ**: โลโก้/หัวเว็บ, ปุ่ม action หลัก (ซื้อเลย, ยืนยัน), active state ของแท็บ/เมนู, accent bar หน้า section header, ลิงก์ "ดูทั้งหมด" — ไม่ใช้สีเขียวกับราคาที่ลดแล้ว (ราคาใช้สีเขียวได้เฉพาะ "ราคาสุดท้ายที่ต้องจ่าย" ไม่ใช่ป้ายลดราคา)
2. **สีแดง `#e53935` / `#e11d48` ใช้กับ**: ป้ายลดราคา (%), ราคาก่อน-หลังส่วนลด, tag "โปรโมชัน", ปุ่ม/สถานะเร่งด่วน (เช่น ตะกร้าสินค้า badge) — ไม่ใช้สีแดงเป็นปุ่ม action หลัก
3. **ฟอนต์ต้องเป็น Noto Sans Thai เท่านั้น** (`family=Noto+Sans+Thai:wght@300;400;500;600;700`) โหลดผ่าน Google Fonts — ห้ามใช้ font ไทยอื่นแทน เพราะ n้ำหนักตัวอักษร (300–700) ถูกออกแบบมาให้ใช้ตามระดับความสำคัญของข้อความ
4. **ไอคอนต้องเป็น Phosphor Icons** (`ph`, `ph-fill` classes จาก `unpkg.com/@phosphor-icons/web`) — ห้ามผสมไอคอนชุดอื่น (เช่น FontAwesome, Material Icons) เข้ามาในหน้าเดียวกัน
5. **การ์ดหนังสือ (book card) มี 3 สไตล์ป้าย ห้ามผสมกันในกริดเดียว**: (ก) ป้ายลด % มุมซ้ายบน, (ข) ริบบอน "Best Seller" มุมขวาบน, (ค) เหรียญอันดับ (rank badge 1/2/3) มุมซ้ายบนแบบวงกลม — ให้เลือกสไตล์เดียวต่อหนึ่ง section ตามความหมาย: อันดับ → ใช้กับ section "ขายดี" เท่านั้น, ริบบอนเบสต์เซลเลอร์ → ใช้แซมในกริดทั่วไปได้, ป้าย % ใช้ได้ทุกที่ที่มีส่วนลดคู่กับสไตล์อื่นได้

## ไฟล์อ้างอิง

| ไฟล์ | เนื้อหา |
|---|---|
| `references/design-tokens.md` | สี, ฟอนต์, ไอคอน, radius, shadow, breakpoint, container width |
| `references/components.md` | Header/Nav, Sidebar, Banner carousel, Section wrapper, Book card (3 แบบ), Price box, CTA buttons, Info/Alert box, Footer (2 แบบ) — พร้อมตัวอย่างโค้ด Tailwind |
