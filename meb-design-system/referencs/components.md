# Components — Meb E-book Store

คอมโพเนนต์ทั้งหมดที่พบในหน้าเว็บต้นแบบ 3 หน้า พร้อมกฎการใช้งานและตัวอย่างโครงโค้ด (ไม่ใช่โค้ดเต็ม ให้ดูโค้ดเต็มในเอกสารต้นฉบับที่แนบมา)

## 1. Header (แถบบนสุด)

- พื้นหลังเขียวแบรนด์ `bg-meb-green`, `sticky top-0 z-50`, สูง `h-14` (แบบเรียบ) หรือ `h-16` (แบบเต็ม)
- โครง: `[โลโก้ + hamburger (มือถือ)] --- [ช่องค้นหา ถ้ามีที่ว่างพอ] --- [ตะกร้า | โปรไฟล์]`
- โลโก้ตัวอักษร "meb" ตัวหนา `text-2xl`/`text-3xl font-black tracking-tighter`
- ช่องค้นหา: ซ่อนบนมือถือ (`hidden md:flex`), มีปุ่มแว่นขยายลอยแทนบนมือถือ
- เวอร์ชันเต็ม (doc 3) มี dropdown หมวดหมู่ฝังในช่องค้นหาด้านซ้าย + ปุ่มค้นหาสีเหลือง `#ffc107` แยกจากพื้นหลังเขียว เพื่อให้ปุ่มค้นหาเด่น
- ไอคอนตะกร้ามี badge ตัวเลขสีแดงมุมขวาบน (`absolute -top-1 -right-2 bg-red-500 ... rounded-full`)

**ใช้เมื่อไหร่**: ทุกหน้า ต้องมี header เดียวกันเป๊ะ ห้ามออกแบบใหม่ต่อหน้า

## 2. Secondary Nav (แถบเมนูรอง สีขาว)

สองรูปแบบที่พบ เลือกใช้ตามความหนาแน่นของเนื้อหา:

- **แบบ tabs แนวนอน scroll ได้** (doc 1): "อีบุ๊กทั้งหมด" เป็นหัวข้อกลาง + แถวแท็บ (หน้าแรก/ขายดี/มาใหม่/โปรโมชัน ฯลฯ) เลื่อนแนวนอนได้บนมือถือ (`overflow-x-auto hide-scrollbar`), tab active มี `border-b-2 border-meb-green text-meb-green`
- **แบบ breadcrumb-in-category** (doc 2, หน้ารายละเอียด): ใช้แถบนี้โชว์หมวดหมู่ที่เกี่ยวข้องกับสินค้าเป็นลิงก์ (ไม่ใช่ tab ทั่วไป) + breadcrumb จริงอยู่ใต้ nav อีกที
- **แบบเต็มมีปุ่ม "หมวดหมู่ทั้งหมด" ก่อนแท็บ** (doc 3): ปุ่มดรอปดาวน์ซ้ายสุดคู่กับไอคอน list ตามด้วยแท็บ พร้อมไอคอนกำกับแต่ละแท็บ (`ph-trend-up` ขายดี, `ph-sparkle` มาใหม่ เป็นต้น), แท็บโปรโมชันใช้สีแดงแทนสีเทาเริ่มต้นเพื่อดึงสายตา

**กฎ**: ซ่อนทั้งแถบบนมือถือได้ (`hidden md:block`) ถ้าเนื้อหาเยอะเกินไป แต่ต้องมี breadcrumb แทนที่เสมอในหน้ารายละเอียด/หน้าลึก

## 3. Sidebar หมวดหมู่ (เฉพาะเดสก์ท็อป)

- กว้างคงที่ `w-[240px]`, `sticky top-[80px]`, `hidden lg:block`
- หัวกล่องพื้นเขียวมี ไอคอน + "เลือกหมวดหมู่"
- รายการเป็น `<ul>` แบ่งเส้นบางๆ (`divide-y divide-gray-100`), รายการสุดท้ายเป็นลิงก์ตัวหนาสีเขียว "ดูหมวดหมู่ทั้งหมด →" ตัวเด่นกว่ารายการอื่น

**ใช้เมื่อไหร่**: เฉพาะหน้าที่เป็น "รายการเนื้อหา" (home, listing หมวดหมู่) ที่ต้องการให้ผู้ใช้กรอง/เลือกหมวดง่ายๆ — **ไม่ใช้ใน**หน้ารายละเอียดสินค้า (เปลืองพื้นที่ ผู้ใช้โฟกัสสินค้าเดียว)

## 4. Banner Carousel

- แถวรูปเลื่อนแนวนอนแบบ snap scroll: `flex overflow-x-auto hide-scrollbar snap-x snap-mandatory`
- การ์ดละ 1 แบนเนอร์เต็มความกว้าง (โปรโมชันใหญ่) หรือหลายใบย่อยแสดงพร้อมกันบนเดสก์ท็อป (`w-[85%] md:w-[45%] lg:w-[32%] snap-center`)
- แบบเต็มมีปุ่มลูกศรซ้าย/ขวาลอย (โผล่ตอน hover: `opacity-0 group-hover:opacity-100`) และจุด pagination ด้านล่าง (`w-2 h-2 rounded-full bg-white` / `bg-white/50` สำหรับ non-active)

**ใช้เมื่อไหร่**: เฉพาะหน้าแรก/หน้ารวมโปรโมชัน — ไม่ใช้ในหน้ารายละเอียดสินค้าหรือหน้า transactional (checkout ฯลฯ)

## 5. Section Wrapper (กล่องขาวห่อแต่ละหมวด)

โครงมาตรฐานทุก section บนหน้ารายการ:

```
<section class="bg-white rounded-lg/xl p-4 md:p-5 shadow-sm border border-gray-100/200 mb-8/10">
  <div class="flex items-center justify-between mb-4/5 border-b border-gray-100 pb-2/3">
    <h2 class="text-lg/xl font-bold flex items-center gap-2">
      [accent bar สีเขียว หรือ ไอคอนสี] ชื่อ section
    </h2>
    <a class="text-sm font-medium text-meb-green hover:underline">ดูทั้งหมด ></a>
  </div>
  [grid การ์ด]
</section>
```

- accent ก่อนชื่อ section มี 2 แบบ: (ก) แท่งสีเขียวบาง `w-1/1.5 h-6 bg-meb-green rounded-full/sm` (ข) ไอคอน Phosphor สีเฉพาะเรื่อง (เช่น `ph-fill ph-trophy text-[#ffaa00]` สำหรับขายดี, `ph-fill ph-gift text-pink-500` สำหรับฟรีกระจาย) — เลือกไอคอนสีเมื่อ section นั้นมีความหมายเฉพาะตัวชัดเจน (รางวัล/ของฟรี) เลือกแท่งสีเขียวเมื่อเป็น section ทั่วไป (เช่น "มาใหม่")

## 6. Book Card (การ์ดหนังสือ) — คอมโพเนนต์สำคัญที่สุด

โครงร่วมของทุกแบบ:

```
<div class="group flex flex-col cursor-pointer">
  <div class="relative w-full aspect-[2/3] (หรือ aspect-[1/1.4]) rounded-md overflow-hidden shadow-sm border mb-2">
    <img ... class="w-full h-full object-cover group-hover:scale-105 transition duration-300">
    [badge/ribbon ถ้ามี]
  </div>
  <h3 class="text-sm font-bold line-clamp-2 mb-1 group-hover:text-meb-green transition">ชื่อหนังสือ</h3>
  <p class="text-xs text-slate-500 line-clamp-1">ผู้แต่ง</p>
  <p class="text-[10px] text-slate-400 mb-2">หมวดหมู่/สนพ.</p>
  <div class="mt-auto flex items-end justify-between">
    [rating ดาว] [ราคา]
  </div>
</div>
```

### 3 สไตล์ป้าย (badge) — ใช้แยกความหมาย ห้ามผสมในกริดเดียวกันแบบสุ่ม
| สไตล์ | ตำแหน่ง | ใช้เมื่อ |
|---|---|---|
| ป้าย % ส่วนลด | มุมซ้ายบนของรูป, สี่เหลี่ยมมน `rounded-br-md`, พื้นแดง | มีส่วนลดจริง ไม่ว่า section ไหน |
| ริบบอน "Best Seller" | มุมขวาบน แบบ ribbon พับมุม (`.ribbon` class), พื้นแดงเข้ม | เน้นว่าเล่มนี้ขายดี แต่ section ไม่ใช่ "อันดับ" โดยตรง (ใช้แซมในกริดทั่วไป) |
| เหรียญอันดับ (rank badge) | มุมซ้ายบนแบบวงกลมลอยออกนอกการ์ด (`.rank-badge`, `top:-10px; left:-10px`) เลข 1/2/3/4+ | เฉพาะ section "ขายดีประจำสัปดาห์/เดือน" ที่มีการจัดอันดับจริง — ห้ามใช้ปนกับ badge อื่นในการ์ดเดียวกัน |

### Rating stars
- ใช้ 5 ไอคอนดาว, เต็ม = `ph-fill ph-star text-yellow-400`, ครึ่งดวง = `ph-fill ph-star-half`, ว่าง = `ph ph-star text-slate-300`
- ถ้ายังไม่มีรีวิว ให้แสดงดาว 5 ดวงสีเทาจางทั้งหมด (`text-slate-300`) แทนที่จะซ่อนแถวไปเลย เพื่อโครงสร้างการ์ดเท่ากันทุกใบ

### ราคา
- มีราคาปกติ: ปุ่มพื้นเขียว ตัวหนังสือขาว `bg-meb-green ... text-xs font-bold px-2 py-1 rounded` (สไตล์การ์ดย่อย) หรือ ตัวเลขเขียวเปล่าไม่มีปุ่ม `text-sm font-bold text-meb-green` (สไตล์การ์ดหนาแน่น)
- มีส่วนลด: ราคาปกขีดฆ่าสีเทาจาง (`line-through text-slate-400`) อยู่บนราคาใหม่สีเขียว/แดงตามบริบท — ในกริดทั่วไปใช้เขียวเป็นราคาสุดท้าย, ในหน้ารายละเอียดสินค้าใช้ "แดง" เป็นราคาสุดท้ายเพื่อเน้นความคุ้ม (ดู price box)

## 7. Price Box (กล่องราคา + ปุ่มซื้อ) — เฉพาะหน้ารายละเอียดสินค้า

- พื้นหลังเหลืองอ่อน `#fcf8e3` ขอบ `#faebcc` มุมโค้ง `rounded-lg`
- แถบมุมขวาบนสีแดงระบุระยะเวลาโปรโมชัน ("โปรโมชันสุดพิเศษ เหลือ N วัน")
- ราคาใหญ่สีแดง `text-3xl font-bold text-price-red` คู่กับราคาปกขีดฆ่า และ "ประหยัด N%"
- ปุ่มคู่: ปุ่ม outline สีเขียว (secondary action เช่น "ทดลองอ่าน") + ปุ่มพื้นเขียวเข้ม shadow-md (primary action "ซื้อเลย" พร้อมไอคอนตะกร้า)
- ใต้กล่องมีแถว secondary actions แบบ text-link+icon (wishlist, ซื้อเป็นของขวัญ) คั่นด้วยเส้นบางบนสุด

**ใช้เมื่อไหร่**: เฉพาะหน้ารายละเอียดสินค้า/หน้าที่มี CTA ซื้อเดี่ยวๆ ชัดเจน — ไม่ใช้ในหน้ารายการ (การ์ดใช้ปุ่มราคาเล็กพอ)

## 8. Info/Alert Box (กล่องแจ้งเตือนรอง)

- โทนฟ้าอ่อน `#e3f2fd`/border `#bbdefb`, ข้อความ `#1976d2`/`#1565c0`, มีปุ่มเล็กพื้นฟ้าเข้มมุมขวา
- ใช้แจ้งข้อมูลเสริมที่ไม่ใช่ error/warning จริงจัง (เช่น "มีขายที่อื่นด้วย") — วางท้ายเนื้อหาหลัก ก่อน footer

## 9. Info Grid (ตารางข้อมูลสินค้า)

- `grid grid-cols-1 sm:grid-cols-2 gap-y-4 gap-x-6` พื้นเทาอ่อน `bg-gray-50` bo กรอบมน
- แต่ละแถว: label สีเทาความกว้างคงที่ (`w-24 text-slate-500`) + value (`flex-1`)
- ใช้แสดง metadata ที่มีคู่ label-value ชัดเจน (ซีรีส์, นักวาด, ประเภทไฟล์, วันวางขาย ฯลฯ)

## 10. Tags

- pill เล็ก `rounded-full text-xs px-2.5 py-1`
- tag หลัก (หมวดหมู่หลักของสินค้า): พื้น `bg-meb-light text-meb-hover`, hover กลายเป็นพื้นเขียวเข้มตัวขาว
- tag รอง: พื้นเทา `bg-gray-100 text-slate-600`, hover `bg-gray-200`

## 11. Social Share Buttons

- ปุ่มวงกลม `w-9 h-9 rounded-full` สีตามแบรนด์จริงของแพลตฟอร์ม (Facebook `#1877F2`, X `#000000`, Line `#00B900`) + ปุ่มคัดลอกลิงก์พื้นเทา

## 12. Footer — 2 แบบ

- **แบบเรียบ (doc 1, 2)**: พื้นขาว ข้อความเดียวลิขสิทธิ์กลางหน้า `border-t border-gray-200 py-8`
- **แบบเต็ม (doc 3)**: พื้นเข้ม `#1f2937` ตัวหนังสือเทาอ่อน แบ่ง 4 คอลัมน์ (เกี่ยวกับ/หมวดหมู่ยอดนิยม/ดาวน์โหลดแอป+โซเชียล) ปิดท้ายด้วยเส้นคั่นและลิขสิทธิ์เล็กกลางหน้า

**กฎเลือกใช้**: หน้าแรก/หน้าที่เป็น "landing" ใช้ footer แบบเต็ม (มีข้อมูลเยอะ ช่วย SEO/นำทาง) หน้าลึกๆ ที่โฟกัสงานเดียว (รายละเอียดสินค้า, checkout) ใช้ footer แบบเรียบเพื่อไม่ดึงความสนใจออกจาก CTA
