# เอกสารข้อกำหนดการออกแบบ (Design Specification Document)
## Responsive Grid System & Layout Organization based on Eye-Tracking Theories

เอกสารฉบับนี้เป็นคู่มือมาตรฐานทางวิศวกรรมการออกแบบและการจัดวางเลย์เอาต์ (Page Layout) เพื่อการเข้าถึงง่าย (Usability) และการเพิ่มยอดการสมัครสมาชิก (Conversion Rate Optimization: CRO) สำหรับเว็บไซต์ห้องสมุดออนไลน์ E-Library โดยบูรณาการข้อมูลเชิงปริมาณด้านสถาปัตยกรรมข้อมูล (Information Architecture) ระบบกริดสากล (Grid System) และทฤษฎีจิตวิทยาพฤติกรรมการมองเห็นของผู้ใช้งานเข้าไว้ด้วยกันอย่างเป็นระบบ

---

## 1. ตารางข้อกำหนดกริดแบบยืดหยุ่นตามหน้าจอ (Responsive Grid Specification Table)

การออกแบบระบบดิจิทัล (Digital Design) จำเป็นต้องคำนึงถึงการแสดงผลที่ถูกต้อง ยืดหยุ่น และตอบสนองได้ทันทีบนอุปกรณ์ที่หลากหลาย (Responsive Web Design) เพื่อเอื้อประโยชน์ต่อประสบการณ์การใช้งานที่ดีของผู้ใช้สูงสุด [55, 117, 177, 236, 254] ระบบกริดจะแบ่งส่วนประกอบหลักออกเป็น **Column** (ช่องแนวยาว), **Gutter** (ระยะห่างระหว่างช่อง) และ **Margin** (ระยะห่างจากขอบจอถึงเนื้อหา) เพื่อสร้างความเป็นระเบียบและสัดส่วน [137] 

ด้านล่างนี้คือตารางสเปกระบบ Grid System มาตรฐานสำหรับใช้ในการตั้งค่าบนเครื่องมือดีไซน์อย่าง Figma และการเขียนโค้ดฝั่ง Frontend (CSS Grid & Flexbox) [139, 177]:

| :--- | :--- | :---: | :--- | :--- | :--- | :--- |

## 2. ทฤษฎีจิตวิทยาการมองเห็นและการจัดวางองค์ประกอบ (Eye-Tracking Theories & Layout Composition)

จากข้อมูลวิจัย Eye-Tracking เผยพฤติกรรมที่สอดคล้องกันว่า มนุษย์มีรูปแบบการกวาดสายตาเพื่อประมวลผลหน้าเว็บที่แตกต่างกันตามสไตล์ของเนื้อหาและการจัดลำดับขั้นสายตา (Visual Hierarchy) [222, 223] หากผู้ออกแบบเข้าใจทฤษฎีเหล่านี้ จะสามารถจงใจ "ควบคุมทิศทางและจังหวะสายตา" ของผู้อ่านให้เดินตรงไปสู่เป้าหมายของเว็บได้อย่างแม่นยำ [224]:

### 2.1 Z-Pattern (การกวาดสายตารูปตัว Z)
*   **คำอธิบายเชิงทฤษฎี:** รูปแบบการกวาดสายตาตามธรรมชาติของมนุษย์บนหน้าเว็บที่มีเนื้อหาไม่หนาแน่นจนเกินไป (Loose/Visual-heavy Pages) เช่น หน้าแรก (Home Page) หรือหน้า Landing Page ด้านบนสุดที่เน้นการสร้างอารมณ์ร่วม [224, 276, 277]. สายตาจะเคลื่อนที่จาก **มุมบนซ้าย -> พุ่งข้ามเป็นเส้นแนวนอนไปมุมบนขวา -> ทะแยงเฉียงลงล่างซ้าย -> และสิ้นสุดที่มุมล่างขวา** [276, 277]
*   **การประยุกต์ใช้จัดวางองค์ประกอบ:**
    1.  **จุดที่ 1 (มุมบนซ้าย):** วางสัญลักษณ์ที่ระบุตัวตนได้ชัดเจน เช่น **Logo ของ E-Library** เพื่อแสดงตนทันทีว่าผู้ใช้เข้ามาถูกเว็บไซต์ [116, 235]
    2.  **จุดที่ 2 (มุมบนขวา):** วางตัวเลือกหรือปุ่มสำคัญลำดับรอง เช่น เมนูนำทางอย่างย่อ, ปุ่มสลับเปลี่ยนภาษา หรือปุ่ม "สมัครสมาชิก" (Secondary Action) [235]
    3.  **จุดที่ 3 (แนวเส้นทแยงตรงกลาง):** วาง **พาดหัวหลัก (Headline)** ที่สื่อสารบอกผลประโยชน์ว่าชีวิตผู้ใช้อ่านจะดีขึ้นอย่างไรภายใน 3-5 วินาที ควบคู่กับภาพประกอบหลัก (Hero Visual) เช่น หน้าจอมือถือแสดงการใช้งาน E-Book เพื่อกระตุ้นอารมณ์ร่วม [29, 51, 151, 152, 295, 296]
    4.  **จุดที่ 4 (มุมล่างขวา):** จุดสุดท้ายที่สายตาจะตกลงมาหลังจากสแกนข้อมูลครบทั้งหมด เป็นตำแหน่งที่เหมาะสมที่สุดในการติดตั้ง **ปุ่ม Call to Action / Call to Value (CTA/CTV)** เช่น ปุ่ม *"เริ่มอ่านฟรีตอนนี้"* หรือกรอกแบบฟอร์มสั้นๆ เพื่อปิดการแปลงผล (Conversion Complete) [154, 235, 298]

### 2.2 F-Pattern (การกวาดสายตารูปตัว F)
*   **คำอธิบายเชิงทฤษฎี:** รูปแบบการกวาดสายตาที่จะเกิดขึ้นเป็นอัตโนมัติบนหน้าเว็บที่มีเนื้อหาเป็นตัวหนังสือจำนวนมาก (Text-heavy Pages) เช่น หน้ารวมรายชื่อบทความ, หน้าค้นหาหนังสือ หรือหน้าสารบัญเนื้อหา E-Book [224]. สายตาจะเริ่มอ่านอย่างละเอียดเป็น **เส้นแนวนอนด้านบนสุด -> เลื่อนลงมาเล็กน้อยอ่านแบบสั้นลง -> จากนั้นจะลากสายตาสแกนตรงลงมาตามขอบซ้าย** โดยละเลยข้อมูลที่อยู่ขอบขวาล่างไปเลย [224]
*   **การประยุกต์ใช้จัดวางองค์ประกอบ:**
    1.  **พาดหัวที่สำคัญที่สุดและคีย์เวิร์ดเด่น (High-value Keywords):** ต้องถูกบรรจุอยู่ใน **2 บรรทัดแรกสุด** ของการอ่านเสมอ เพื่อดักพฤติกรรมการกวาดสายตาแบบกว้างด้านบน [224]
    2.  **การวางพาดหัวย่อย (Sub-headlines):** หรือประเภทย่อยของหนังสือ ควรจัดวางแบบ **ชิดซ้าย (Left-aligned)** และใส่คีย์เวิร์ดตัวหนาเพื่อช่วยลดภาระทางสมอง (Cognitive Load) ให้ผู้ใช้อ่านไล่เรียงหัวข้อลงไปตามแนวตั้งทางด้านซ้ายได้สะดวกรวดเร็ว [65, 77, 224]
    3.  **หลีกเลี่ยงการวางปุ่มแปลงผล (CTA):** ไว้ทางด้านขวาล่างของส่วนที่มีเนื้อหาข้อความยาวๆ เพราะผู้ใช้ที่มองตามแนวรูปตัว F จะกวาดสายตาไปไม่ถึง ส่งผลให้อัตราการคลิกปุ่มต่ำลงอย่างน่าใจหาย

### 2.3 Gutenberg Diagram / Gutenberg Gravity (แผนภูมิคูเทนเบิร์ก)
*   **คำอธิบายเชิงทฤษฎี:** แผนภูมิการแบ่งพื้นที่จอภาพออกเป็น 4 ส่วนหลัก โดยอิงจากสัญชาตญาณ "แรงโน้มถ่วงของการอ่าน" (Reading Gravity) จากซ้ายไปขวา และจากบนลงล่าง ประกอบด้วย:
    1.  *Primary Optical Area* (ส่วนบนซ้าย): จุดเริ่มต้นการมองเห็นแรกสุดของผู้ใช้
    2.  *Strong Fallow Area* (ส่วนบนขวา): จุดพักสายตาขั้นที่สอง แต่ไม่เน้นการจำ
    3.  *Weak Fallow Area* (ส่วนล่างซ้าย): จุดบอดของสายตาที่คนมักจะเผลอข้ามไปเลย
    4.  *Terminal Area* (ส่วนล่างขวา): จุดพักสายตาสุดท้ายก่อนที่ผู้ใช้จะเปลี่ยนไปทำกิจกรรมอื่นหรือเลื่อนหน้าเว็บลงล่าง
*   **การประยุกต์ใช้จัดวางองค์ประกอบ:**
    *   ห้ามวางฟอร์มข้อมูลสำคัญหรือปุ่ม CTA ไว้ที่ฝั่งซ้ายล่าง (Weak Fallow Area) เนื่องจากคนส่วนใหญ่จะกวาดข้ามไปโดยไม่สนใจ
    *   **ปุ่ม "ส่งฟอร์ม" หรือ "สมัครสมาชิก" (Call to Value) ต้องอยู่ในเขต Terminal Area (ขวาล่าง)** เพื่อสอดรับกับจังหวะสุดท้ายที่ผู้ใช้อ่านข้อมูลจบกระบวนการแล้วเกิดการประเมินเพื่อตัดสินใจลงมือทำอย่างสมบูรณ์แบบ [154, 298]

### 2.4 Attention Path & Progressive Disclosure (เส้นทางสะกดสายตาแบบเป็นขั้น)
*   **คำอธิบายเชิงทฤษฎี:** การออกแบบหน้าเว็บไม่ควรสุ่มวางข้อมูลที่อยากพูดทั้งหมดลงไปในหน้าจอเดียว เพราะจะสร้างสิ่งรบกวนและความสับสนจนผู้ใช้ออกจากเว็บ (Bounce) [116, 288]. แต่ต้องใช้หลักการค่อยๆ เผยแพร่ข้อมูลไปทีละขั้นอย่างชาญฉลาด (**Progressive Disclosure**) โดยลำดับข้อมูลแต่ละเซกชัน (Section) ให้มีความโดดเด่นทางสายตาดึงดูดลดหลั่นกันลงมาทีละน้อยอย่างเป็นธรรมชาติ [80, 226]:
    1.  **The Entry Point (ด่านแรก):** คือสปอตไลท์สำคัญที่มี Contrast สูงสุดเพื่อบอกความเจ๋งของ E-Library หยุดคนดูให้อยู่หมัดตั้งแต่ 3 วินาทีแรก [151, 225, 295]
    2.  **The Progression (เนื้อหาทอยลื่น):** ค่อยๆ ขยี้ปัญหา (Pain Point) และยื่นข้อเสนอที่เป็นฟีเจอร์เด็ดของระบบ (เช่น ระบบจดบันทึกย่อบนหน้ากระดาษ, ระบบวิเคราะห์การอ่านด้วย AI) เพื่อแสดงว่าคุณเข้าใจและมอบประโยชน์ให้ชีวิตเขาดีขึ้นได้จริง [152, 153, 225, 296]
    3.  **The Destination (จุดเปลี่ยนใจ):** วางระบบความน่าเชื่อถืออย่าง **Trust Signals / Social Proof** เช่น รีวิวที่มีรูปถ่ายจริงจากนักอ่าน หรือยอดสถิติผู้เข้าใช้งานสะสมใกล้ๆ กับปลายทางปุ่ม CTA เพื่อลดความกังวลใจและสร้างความไว้วางใจในการสมัคร [117, 153, 211, 214, 225, 297]

## 3. ผังพิมพ์เขียวการวางเลย์เอาต์ระบบ Responsive (Responsive Layout Blueprint Guide)

เพื่อให้นักพัฒนาสร้างและจัดแถว Grid แบบ CSS ได้อย่างไม่มีข้อผิดพลาด ด้านล่างนี้คือแนวทางโครงสร้าง Grid และโมดูลที่ควรแสดงในแต่ละหน้าจอของห้องสมุด E-Library:

### 3.1 รูปแบบการแสดงผลบนหน้าจอ Desktop (12-Column Grid)
*   **ส่วน Header (Above the Fold):** ใช้สัดส่วน 12 Columns เต็มขอบกว้าง. 
    *   *Columns 1-3:* สัญลักษณ์ Logo แบรนด์ (จัดชิดซ้ายเพื่อเป็นจุด Entry Point ของตัว Z-Pattern) [276]
    *   *Columns 4-8:* ช่องค้นหาหนังสือ E-Book ด่วนแบบพิมพ์ปุ๊บเจอเลย (Instant Search Bar)
    *   *Columns 9-12:* ปุ่ม CTA "สมัครสมาชิกเข้าใช้ฟรี" (จัดชิดขวาเพื่อเป็นจุด Terminal Area)
*   **ส่วน Hero Section (ครึ่งหน้าบนสุด):**
    *   *Columns 1-6 (ชิดซ้าย):* พาดหัวสะกดใจ Headline + Sub-headline อักษรชิดซ้ายเป็นระเบียบชัดเจน [65]
    *   *Columns 7-12 (ชิดขวา):* Hero Visual (วิดีโอแนวตั้ง UGC หรือภาพ 3D ปกหนังสือน่าอ่านสไตล์ Explorecore สีเบจธรรมชาติสบายตา) [8, 152]
*   **ส่วนเนื้อหาคุณประโยชน์ (Feature Sections):**
    *   ใช้รูปแบบแบ่ง Columns เป็น **3 Blocks ย่อยเท่าๆ กัน (คนละ 4 Columns)** แสดงไอคอนฟีเจอร์เด่น เช่น 1. คลังหนังสือแสนเล่ม 2. อ่านออฟไลน์ได้ 3. สรุปเนื้อหาด้วยระบบอัจฉริยะ เพื่อให้ผู้ใช้อ่านจัดหมวดหมู่ข้อมูลได้สบายตาที่สุด [268]

### 3.2 รูปแบบการแสดงผลบนหน้าจอ Tablet / iPad (8-Column Grid)
*   **ส่วน Header (บนสุด):** ยุบเมนูนำทางและปุ่มค้นหาไปซ่อนไว้ภายใต้สัญลักษณ์ไอคอนสามขีด (Hamburger Menu) ที่ชิดขวาของจอ (Columns 7-8) เพื่อป้องกันหน้าจอรกและลดภาระสายตา [84] ส่วนโลโก้ยังคงอยู่มุมซ้ายที่ Columns 1-2.
*   **ส่วน Hero Section:**
    *   *Columns 1-4:* ข้อความพาดหัวหลักและปุ่ม CTA สเกลขนาดเล็กลงมา
    *   *Columns 5-8:* ภาพประกอบปกหนังสือเคลื่อนไหวเบาๆ มีการวาง Grid แบบ Modular สี่เหลี่ยมสมมาตรเรียบร้อยสะดุดตา [138]

### 3.3 รูปแบบการแสดงผลบนหน้าจอ Mobile (4-Column Grid)
*   **กลยุทธ์ Single-Column Stack:** ทุกองค์ประกอบข้อมูลต้องถูกเปลี่ยนรูปและ **เรียงซ้อนพับลงมาในแนวดิ่งแบบ 1 คอลัมน์ยาวลงล่าง (Vertical Stack)** เพื่อประหยัดพื้นที่บนหน้าจอขนาดเล็กและอำนวยความสะดวกในการไถจอนิ้วโป้ง [236]:
    *   *บนสุด:* โลโก้แบรนด์ E-Library ขนาดกะทัดรัด (ชิดซ้าย) เคียงข้างด้วยไอคอนค้นหาด่วนและ Hamburger Menu (ชิดขวา)
    *   *ถัดมา:* พาดหัวสะดุดใจ (Headline) จัดวางอยู่ตรงกลาง (Center-aligned) หรือชิดซ้าย เพื่อให้ประมวลผลข้อมูลได้สั้นรวดเร็วภายใน 3 วินาที [151, 295]
    *   *ถัดมา:* ปุ่ม Call to Value แผ่นกว้างชิดขอบจอเพื่อให้แตะง่าย (เช่น ปุ่มกว้างเต็มหน้าจอสัมผัสขนาดใหญ่พอสำหรับนิ้วโป้ง) [84, 117]
    *   *จุดวางปุ่ม CTA ซ้ำกระจัดกระจาย:* หน้าจอมือถือจะยาวมาก ให้ทำการแทรกปุ่ม CTA ลงไปในเลย์เอาต์ทุกๆ ระยะการปัดหน้าจอ 2-3 ช่วง เพื่อป้องกันไม่ให้ผู้ใช้เหนื่อยกับการเลื่อนขึ้นด้านบนสุดเวลาตัดสินใจกรอกสมาชิกได้สำเร็จ [159]
