# Relevant Resources & Tools (Project Skill)

## Overview
Automated software development framework integrating four core methodologies:
1. **Caveman**: Minimalist boilerplate and clean project structure patterns.
2. **Superpowers**: Structured agentic development methodologies (TDD, systematic debugging, subagents, brainstorming).
3. **TOON (Token-Oriented Object Notation)**: Token-efficient serialization format for JSON data and prompt context.
4. **Headroom**: Agentic skill expansion, context optimization, and workspace plugins.

## Automatic Invocation Rules (Brain Directives)
You MUST automatically apply these resources during task execution without waiting for explicit user prompts:

### 1. Caveman Project Architecture & Boilerplate
- **Trigger**: Creating new features, refactoring directory structure, or setting up boilerplates.
- **Action**: Reference [Caveman](https://github.com/JuliusBrussee/caveman/blob/main/README.md) for clean, minimalist, feature-grouped structure. Avoid deep nesting and bloated dependencies.

### 2. Superpowers Agentic Workflows
- **Trigger**: Every development cycle, bugfix, or feature implementation.
- **Action**: Apply [Superpowers](https://github.com/obra/superpowers/) core principles:
  - **Brainstorming**: Explore requirements and design options before coding complex features.
  - **TDD**: Write failing test before implementation code.
  - **Systematic Debugging**: Inspect full un-truncated logs before diagnosing errors.
  - **Subagents**: Dispatch isolated subagents for independent parallel tasks.
  - **Verification**: Run tests and empirical verification before claiming completion.

### 3. TOON Token-Oriented Data Serialization
- **Trigger**: Serializing JSON arrays, database output, logs, or multi-object payloads in prompts.
- **Action**: Use [TOON](https://github.com/toon-format/toon) tabular/compact notation to compress JSON data representation, saving 60-80% of prompt tokens.

### 4. Headroom Workspace & Skill Plugin System
- **Trigger**: Managing agent skills, environment capabilities, and context headroom.
- **Action**: Utilize [Headroom](https://github.com/headroomlabs-ai/headroom) to manage context limits and expand workspace agent skills.
